WORLD WIDE WEB — NEXT PAGES

Files included:
  portal-next.html       launcher for these additions
  old-museum.html        Old Museum
  flight-track.html      Flight Track
  canterbury-tools.html  Canterbury Tools
  old-search.html        Old Search Engine
  style.css              shared first-iPhone-era styling

Design:
  - 320px page width
  - simple blue navigation bar
  - rounded list rows inspired by early iPhone Safari web UI
  - no external JavaScript libraries
  - no custom icon artwork
  - pages can be hosted together in one directory

Behavior:
  - Flight Track sends an entered flight number to FlightAware's live tracker.
  - Old Search sends a query to Google Search.
  - Canterbury Tools links to Canterbury School's current public pages.
